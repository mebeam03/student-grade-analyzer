# Student Grade Analyzer

**Python | Matplotlib | Seaborn**

## Project Overview

This project is an interactive Python program designed to collect, calculate, and visualize student grades. Users enter student names and individual scores, which are stored in a dictionary and processed to calculate each student's average and corresponding letter grade.

The program then generates a bar chart displaying the frequency of each letter grade across the student population.

## Features

- Collects student names and multiple grades through user input
- Stores student records using Python dictionaries
- Calculates individual grade averages
- Assigns letter grades using conditional statements
- Counts the frequency of each letter grade
- Visualizes grade distributions using Seaborn and Matplotlib

## Skills Demonstrated

- Python functions and loops
- Dictionaries and lists
- Conditional logic
- Data aggregation and calculations
- Basic input validation
- Data visualization
